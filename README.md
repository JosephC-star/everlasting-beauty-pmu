# Everlasting Beauty PMU by Julie

A responsive portfolio and services website for Everlasting Beauty PMU in Searcy, Arkansas.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy on Netlify

Connect this repository to Netlify. No build command is required, and the publish directory is `.`.

## Updating content

- Service prices are in `index.html` under the `#services` section.
- Portfolio photos are in `assets/`.
- Colors and layout are controlled by `styles.css`.

Client photographs are used with permission provided to the business owner.
